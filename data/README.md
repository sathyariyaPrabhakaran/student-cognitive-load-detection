# Dataset

Place the real `dataset.csv` in this folder.

Expected feature columns:

```text
ear
mar
blink_count
yawn_count
head_movement
typing_speed
mouse_speed
keyboard_idle
mouse_idle
mouse_clicks
study_time
cognitive_load
```

The repository intentionally does not include a copied third-party dataset. Check the source dataset's license/terms before redistribution.
